# KylinAssistant (麒麟助手)

[中文](README.zh.md)

![KylinAssistant Logo](resources/logo_256.png)

A tray-resident, single-instance utility that schedules smooth shutdowns and previews disk cleanup via GUI or CLI.

## Features

- **Tray-resident single tabbed window with live status**
- **Scheduled smooth shutdown by delay or clock time with live countdown, instant cancel and graceful app exit**
- **Rule-based disk cleanup with full candidate preview and confirm-before-delete**
- **Command-line mode for every action, including headless machines**
- **Machine-readable output and a "request accepted" instant-return mode**
- **One shared running instance for GUI and CLI — no duplicate state**
- **Plugin-style task organization; no account, no cloud, no telemetry; deletions logged**

## About

KylinAssistant is a single-instance utility set built around a resident tray app with two entry points — a GUI for people and a pure CLI for AI and headless servers — sharing one running instance with identical behavior.
