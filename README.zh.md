# 麒麟助手 KylinAssistant

[English](README.md)

![麒麟助手 Logo](resources/logo_256.png)

系统托盘常驻的单实例辅助工具集，以图形界面与命令行两种入口提供平滑定时关机与可预览的磁盘清理。

## 功能特性

- **系统托盘常驻的单标签窗口，托盘图标实时显示状态**
- **平滑定时关机：按延迟或指定时刻，实时倒计时、随时取消，先优雅退出应用**
- **规则驱动磁盘清理，先完整预览候选项，确认后才删除**
- **所有动作均有命令行入口，覆盖无显示器机器**
- **面向自动化的机器可读输出，支持「请求已接受」即时返回**
- **GUI 与 CLI 共用同一运行实例，无重复副本与状态冲突**
- **插件式任务组织；无账号、无云、无遥测；删除操作全部留日志**

## 简介

麒麟助手是面向日常使用的单机辅助工具集，以「单例常驻 + 双模式入口」为核心：系统托盘常驻的图形界面供人使用，纯命令行模式供 AI 与无桌面服务器使用，两种入口共享同一运行实例，行为完全一致。
